# Цель

Создать или расширить структурированную архитектурную документацию в `docs/` под указанную область.

**Область:** `$ARGUMENTS`

# Как выполнять

1. Если `$ARGUMENTS` пуст — **не** вызывай агента. Спроси у пользователя, с какой области начать. Предложи 3–4 приоритизированных варианта:
   - `architecture` — базовые документы (controllers, hooks, lifecycle). Рекомендую первым.
   - `accounts` — поток учёта (GL, налоги, платежи).
   - `stock` — поток склада (SL-записи, batch/serial).
   - `all` — пройти все области последовательно (несколько сессий).

2. Если пользователю нужен просто исследовательский ответ без постоянной архитектурной документации — направь его к `/research-codebase`. Продолжай только если действительно нужна структурированная архитектурная документация.

3. Делегируй работу сабагенту `architecture-researcher` через Agent tool с `subagent_type: "architecture-researcher"`.

4. В промпте агенту обязательно укажи:
   - Точную область.
   - Любые дополнительные ограничения от пользователя.
   - Язык документации: совпадает с языком запроса пользователя; для смешанных или только-кодовых запросов — English по умолчанию. Уточняй только при реальной неоднозначности.
   - Требование показать план до записи любого файла и дождаться согласования, если создаётся >1 файл.
   - Требование в конце обновить `CLAUDE.md` и `docs/README.md`.

5. **Follow-up по той же области:** вызови агента повторно. Агент обнаружит существующие документы в `docs/` и расширит/исправит их на месте, а не перезапишет или продублирует.

6. Получив ответ агента, передай пользователю его финальный отчёт дословно (созданные файлы, обновлённые файлы, рекомендуемые следующие области). Не дублируй контент встроенным текстом, не добавляй своих комментариев.

# Ограничения

- Не пиши код или документацию напрямую в рамках этой команды.
- Не вызывай других специализированных агентов параллельно с `architecture-researcher`. Сам агент может запускать `Explore`-сабагенты внутри.
- Не обходи и не меняй шаги согласования, заложенные в агента.
