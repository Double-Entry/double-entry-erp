  1. Принять и валидировать аргументы пользователя (`$ARGUMENTS`).
  2. Направить работу нужному специализированному сабагенту.
  3. Передать отчёт сабагента дословно пользователю.

Команда НЕ:
  • Место, где делать работу самому. Если работа содержательная — делегируй.
  • Место обхода правил агента. Никогда не «срезай» шаги согласования агента.
  • Место для собственных комментариев. Не оборачивай отчёт агента в интерпретацию.
  • Место для нескольких параллельных агентов. Пусть агент декомпозирует внутри.

# Как выполнять

<!--
СТРУКТУРА
  Нумерованные шаги, начиная с валидации ввода. Последний шаг всегда — «передать
  отчёт агента дословно». Держи каждый шаг коротким — команды не программы;
  это инструкции для модели.
-->

1. Если `$ARGUMENTS` пуст — **не** вызывай агента. Спроси у пользователя конкретный {{вид-ввода}} и дождись ответа.

2. Если пользователю нужен просто быстрый ответ без сохранения артефакта — скажи, что для этого достаточно задать вопрос напрямую, без этой команды. Продолжай только если действительно нужен сохранённый артефакт.

3. Если вопрос явно {{условие-вне-scope}} — **не** вызывай агента. Перенаправь пользователя к {{альтернативный-путь}}.

4. Делегируй работу сабагенту `{{agent-name}}` через Agent tool с `subagent_type: "{{agent-name}}"`.

5. В промпте агенту обязательно укажи:
   - Точный {{вид-ввода}} дословно.
   - Стартовые файлы/пути, если пользователь их назвал.
   - Границы scope, если пользователь их задал.
   - Язык вывода: совпадает с языком вопроса; для смешанных или только-кодовых вопросов — English по умолчанию. Уточняй только при реальной неоднозначности.

6. **Follow-up по той же теме:** вызови агента повторно. Агент обнаружит существующие артефакты и расширит/исправит на месте, а не создаст дубль.

7. Получив ответ агента, передай его финальный отчёт пользователю **дословно** (путь, summary, open questions). Не дублируй находки встроенным текстом. Не добавляй своих комментариев. Не добавляй своей интерпретации.

# Ограничения

<!--
ЯВНЫЕ ЗАПРЕТЫ
  Перечисли что команда никогда не должна делать. Они зеркалят правила агента,
  чтобы слой команды не подрывал их случайно.
-->

- Не выполняй {{домен-работы}} и не пиши {{вид-артефакта}} напрямую в рамках этой команды — вся содержательная работа идёт через агента.
- Не вызывай других специализированных агентов параллельно с `{{agent-name}}`. Агент может запускать общих сабагентов (например, `Explore`) внутри себя.
- Не обходи и не меняй mandatory-шаги агента (дисклеймер, структуру, sign-off).
- Не интерпретируй находки агента как {{высшая-власть}} при передаче — дисклеймер внутри каждого артефакта является авторитетным.
