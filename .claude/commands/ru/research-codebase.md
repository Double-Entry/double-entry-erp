# Цель

Ответить на исследовательский вопрос по коду и сохранить воспроизводимый отчёт в `docs/research/`.

**Вопрос:** `$ARGUMENTS`

# Как выполнять

1. Если `$ARGUMENTS` пуст — **не** вызывай агента сразу. Спроси у пользователя его исследовательский вопрос или область интереса и дождись конкретного ответа.

2. Как только вопрос определён, делегируй работу сабагенту `codebase-researcher` через Agent tool с `subagent_type: "codebase-researcher"`.

3. В промпте агенту обязательно укажи:
   - Точный вопрос дословно.
   - Стартовые файлы/пути, если пользователь их назвал.
   - Границы scope, если пользователь их задал.
   - Язык итогового документа: совпадает с языком вопроса пользователя; если смешанный или неясно — уточни до вызова агента.

4. Получив ответ агента, передай пользователю его финальный отчёт дословно (путь созданного файла, summary, open questions). Не дублируй находки встроенным текстом, не добавляй своих комментариев.

# Ограничения этой команды

- Не выполняй исследование и не пиши документацию напрямую в рамках этой команды — это работа агента.
- Не обходи и не меняй шаги согласования, заложенные в агента.
- Не вызывай других агентов для этой работы.
