# Цель

Ответить на исследовательский вопрос по коду и сохранить воспроизводимый отчёт в `docs/research/`.

**Вопрос:** `$ARGUMENTS`

# Как выполнять

1. Если `$ARGUMENTS` пуст — **не** вызывай агента. Спроси у пользователя конкретный исследовательский вопрос и дождись ответа.

2. Если пользователю нужен просто быстрый ответ без сохранения документа — скажи, что для этого достаточно задать вопрос напрямую, без этой команды. Продолжай только если действительно нужен сохранённый документ.

3. Делегируй работу сабагенту `codebase-researcher` через Agent tool с `subagent_type: "codebase-researcher"`.

4. В промпте агенту обязательно укажи:
   - Точный вопрос дословно.
   - Стартовые файлы/пути, если пользователь их назвал.
   - Границы scope, если пользователь их задал.
   - Язык итогового документа: совпадает с языком вопроса; для смешанных или только-кодовых вопросов — English по умолчанию. Уточняй только при реальной неоднозначности.

5. **Follow-up по той же теме:** вызови агента повторно. Агент обнаружит существующий документ в `docs/research/` и расширит/исправит его, а не создаст дубль.

6. Получив ответ агента, передай пользователю его финальный отчёт дословно (путь, summary, open questions). Не дублируй находки встроенным текстом, не добавляй своих комментариев.

# Ограничения

- Не выполняй исследование и не пиши документацию напрямую в рамках этой команды.
- Не вызывай других специализированных агентов параллельно с `codebase-researcher`. Сам агент может запускать `Explore`-сабагенты внутри себя.
- Не обходи и не меняй шаги согласования, заложенные в агента.
