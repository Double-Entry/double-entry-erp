# Цель

Ответить на FOSS-лицензионный вопрос по проекту ERPNext и сохранить воспроизводимый четыре-юрисдикционный отчёт в `docs/legal/`. Содержательная правовая база для каждой юрисдикции берётся из четырёх отдельных скиллов под `.claude/skills/` ([legal-ru](.claude/skills/legal-ru/SKILL.md), [legal-us](.claude/skills/legal-us/SKILL.md), [legal-eu](.claude/skills/legal-eu/SKILL.md), [legal-rs](.claude/skills/legal-rs/SKILL.md)) — агент читает их перед написанием каждой юрисдикционной секции.

**Вопрос:** `$ARGUMENTS`

# Как выполнять

1. Если `$ARGUMENTS` пуст — **не** вызывай агента. Спроси у пользователя конкретный FOSS-лицензионный вопрос и дождись ответа.

2. Если пользователю нужен просто быстрый ответ без сохранения документа — скажи, что для этого достаточно задать вопрос напрямую, без этой команды. Продолжай только если действительно нужен сохранённый четыре-юрисдикционный документ.

3. Если вопрос явно вне FOSS-лицензирования (трудовое, корпоративное, налоги, споры по торговым маркам, политики магазинов приложений, советы по принудительному исполнению / litigation, общее privacy/GDPR не привязанное к конкретному пункту лицензии) — **не** вызывай агента. Перенаправь пользователя к квалифицированному юристу в соответствующей юрисдикции.

4. Делегируй работу сабагенту `legal-licensing-researcher` через Agent tool с `subagent_type: "legal-licensing-researcher"`.

5. В промпте агенту обязательно укажи:
   - Точный FOSS-лицензионный вопрос дословно.
   - Стартовые файлы/пути, если пользователь их назвал (`LICENSE`, `pyproject.toml`, `package.json`, конкретная директория зависимости, `license_texts/`).
   - Границы scope, если пользователь их задал (например, «только Python-зависимости», «только core-app, не региональные модули»).
   - Язык итогового документа: совпадает с языком вопроса; для смешанных или только-кодовых вопросов — English по умолчанию. Уточняй только при реальной неоднозначности.

6. **Follow-up по той же теме:** вызови агента повторно. Агент обнаружит существующий документ в `docs/legal/` и расширит/исправит его, а не создаст дубль.

7. Получив ответ агента, передай пользователю его финальный отчёт дословно (путь, summary, open questions). Не дублируй находки встроенным текстом, не добавляй своих комментариев, не добавляй своей юридической интерпретации.

# Ограничения

- Не выполняй юридическое исследование и не пиши документ напрямую в рамках этой команды — весь анализ идёт через агента.
- Не вызывай других специализированных агентов параллельно с `legal-licensing-researcher`. Сам агент может запускать `Explore`-сабагенты внутри себя.
- Не обходи и не меняй mandatory-дисклеймер агента, три-юрисдикционную структуру или шаги согласования.
- Не интерпретируй находки агента как юридическую консультацию при передаче пользователю — дисклеймер в каждом документе является авторитетным.
